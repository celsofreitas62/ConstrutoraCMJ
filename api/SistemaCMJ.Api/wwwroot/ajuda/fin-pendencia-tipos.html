Para que serve: cadastrar os tipos de pendência que aparecem no botão + Pendência da ficha dos lançamentos (ex.: Aguardando nota fiscal, Aguardando contrato, Conferir valor).

Como usar

  • Clique em + Incluir tipo, preencha a linha e clique em Gravar na própria linha.
  • Código: letras sem acento, números e "_" (ex.: AGUARDA_MEDICAO).
  • Vale para: contas a pagar, a receber ou as duas.
  • Bloqueia a baixa: enquanto uma pendência desse tipo estiver aberta, o lançamento não pode ser pago ou recebido.
  • Como resolver: orientação que aparece na ficha para quem for resolver.
  • Abertas: quantas pendências desse tipo ainda estão abertas.

Cuidados

  • Para parar de usar um tipo, desmarque Ativo e grave: ele some do "+ Pendência", mas as pendências já lançadas continuam.
  • Tipos do sistema (ex.: Veio da migração – conferir) não mudam de código nem podem ser desativados.
  • As pendências automáticas (sem centro de custo, sem anexo, vencida há muito tempo...) não são cadastradas aqui: são ligadas e ajustadas nos Parâmetros de uso (FIN_PEND_*).
