Para que serve: o histórico geral do sistema. Mostra tudo o que foi incluído, alterado ou excluído, em qualquer tela, por quem, quando, de qual computador e o valor antes e depois. Ninguém altera nem apaga a auditoria.

Filtros

  • De / Até: período (padrão: os últimos 7 dias).
  • Usuário e Tabela: nome ou parte dele (a tabela é o nome técnico, ex.: Pessoa, Perfil_Permissao).
  • Código do registro, Operação (inclusão, alteração, exclusão) e Lote (o que um processo gerou de uma vez, ex.: uma importação).
  • Mostra até as 2.000 mudanças mais recentes do filtro; para ver mais, estreite o período.

Lista

  • As mudanças ficam agrupadas por operação (o que foi gravado junto). O cabeçalho do grupo mostra data e hora, usuário, computador, rotina de origem e o lote, se houver.
  • Clique no número do lote para ver só o que aquele lote fez.
  • Inclusões e exclusões mostram um resumo do registro; passe o mouse para ver tudo.

Desfazer

  • Desfazer esta operação: volta o que foi gravado naquela operação.
  • Desfazer o lote: volta tudo o que o lote fez, em todas as telas, na ordem inversa.
  • Antes, abre a prévia com cada campo (como está agora e como vai ficar). O motivo é obrigatório. É tudo ou nada: se alguém mexeu depois num daqueles campos, a linha aparece em vermelho e nada é desfeito.
  • Inclusões desfeitas vão para a lixeira (ou são desativadas, conforme a tela). Senha nunca é desfeita.
  • Precisa da permissão Desfazer nesta tela e também na tela de cada registro que vai mudar.
