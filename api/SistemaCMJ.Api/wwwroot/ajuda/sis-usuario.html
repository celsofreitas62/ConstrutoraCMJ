Para que serve: incluir ou alterar um usuário, dar a senha provisória, desbloquear e ajustar permissões só dele.

Aba Dados

  • Login (obrigatório): o que a pessoa digita para entrar. Letras minúsculas, números, ponto, hífen ou sublinhado, sem espaço e sem acento. Ex.: renata, joao.silva. Não pode repetir.
  • Nome (obrigatório): nome completo. Aparece no topo da tela e no histórico.
  • E-mail: para os avisos do sistema. Opcional.
  • Perfil (obrigatório): define o que a pessoa pode fazer em cada tela. Os perfis são cuidados em Sistema › Segurança › Perfis e permissões.
  • Ativo: desmarque para desativar. O usuário não entra mais e as sessões abertas dele são encerradas. Você não pode desativar o seu próprio usuário.

Senha

  • O sistema nunca mostra nem guarda a senha de ninguém: guarda só uma "impressão digital" dela, impossível de reverter.
  • Usuário novo nasce com a senha provisória padrão. Passe a senha para a pessoa pessoalmente (nunca por e-mail). No primeiro acesso ela é obrigada a criar a senha dela.
  • A senha provisória vale por um prazo (padrão: 24 horas). Passado o prazo sem a pessoa entrar, o login recusa: use Reiniciar senha de novo.
  • Reiniciar senha: para quem esqueceu a senha. Volta para a provisória padrão, desbloqueia e encerra as sessões abertas. Pede confirmação.
  • Desbloquear: para quem errou a senha várias vezes e foi bloqueado, mas lembra a senha. A senha continua a mesma.
  • Para trocar a sua senha, use "Trocar senha" no topo da tela.

Aba Permissões individuais

  • O normal é o perfil decidir tudo. Use esta aba só para exceções: dar a uma pessoa algo que o perfil não dá, ou tirar algo que o perfil dá.
  • Marcado = o usuário pode. + verde: dado só a ele. − vermelho: tirado só dele. Voltar a marcação para como está no perfil desfaz a exceção.
  • Usuário administrador tem tudo: não há exceções a marcar.
  • As mudanças desta aba são gravadas junto com o botão Gravar.

Aba Histórico

  • Quem mudou o quê e quando neste usuário. Ninguém altera o histórico. A senha nunca aparece: só a data e a hora em que foi definida.

Atalhos

  • Ctrl+S grava (com a mesma confirmação do botão); Esc volta para a lista; Enter não grava.
