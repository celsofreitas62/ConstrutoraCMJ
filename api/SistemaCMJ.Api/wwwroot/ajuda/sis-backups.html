Para que serve: acompanhar os backups automáticos do banco e, quando for preciso, pedir que o banco volte para um ponto do passado (restauração).

Os backups

  • Completo: todo dia à noite. É a base de qualquer restauração.
  • De hora em hora (log): guarda o que mudou desde o anterior. Com ele dá para voltar para um dia e hora, perdendo no máximo 1 hora.
  • Teste de restauração: toda semana o servidor restaura o último backup numa cópia e confere se está bom.
  • Segurança: feito logo antes de cada restauração, para desfazer se tiver sido engano.
  • Os backups mais antigos são apagados pela limpeza (dias guardados no parâmetro BACKUP_DIAS_MANTER). O topo mostra até onde dá para voltar.

Restaurar

  • Só quem tem a permissão Restaurar (administradores) vê a aba.
  • Escolha um dia e hora ou um backup da lista, escreva o motivo, a palavra RESTAURAR e a sua senha.
  • A tela só registra o pedido. Em até 1 minuto o servidor faz o backup de segurança, tira o sistema do ar para todos por alguns minutos, restaura e religa. Depois, entre de novo.
  • Enquanto o pedido está aguardando, dá para cancelar na aba Pedidos de restauração.
  • O administrador e quem pediu recebem e-mail com o pedido e com o resultado.

Cuidados

  • Tudo o que foi lançado depois do ponto escolhido some do sistema. Avise os outros usuários antes.
  • Restaurou por engano? Faça um pedido novo escolhendo o backup de segurança daquela restauração.
  • Um pedido por vez.
