Para que serve: cadastrar as pessoas que usam o sistema. Cada pessoa tem o seu próprio usuário: assim o histórico mostra quem fez cada coisa. Não compartilhe usuário.

Buscar

  • Digite parte do login, do nome ou do e-mail. A lista atualiza sozinha.
  • Use Perfil para ver só os usuários de um perfil e Situação para ver os desativados.

Colunas

  • Perfil: o que o usuário pode fazer. Se aparecer "+ exceções individuais", ele tem permissões a mais ou a menos que o perfil (veja na ficha).
  • Senha: Definida (ele já criou a dele), Provisória (vai criar no próximo acesso), Provisória vencida (passou do prazo sem trocar), Bloqueado (errou a senha várias vezes) ou Sem senha.
  • Último acesso: a última vez que o usuário entrou.

Botões

  • + Incluir: cadastra um usuário novo. Ele já nasce com a senha provisória padrão.
  • Exportar Excel: baixa a lista da tela num arquivo que o Excel abre (.csv).
  • Clique numa linha para abrir a ficha do usuário (reiniciar senha, desbloquear, permissões individuais, histórico).

Cuidados

  • Quem sai da empresa não é apagado: desmarque "Ativo" na ficha. O histórico do que ele fez continua guardado.
  • Sempre fica pelo menos um administrador ativo: o sistema não deixa desativar o último.
  • Só aparecem os botões que o seu usuário pode usar.
