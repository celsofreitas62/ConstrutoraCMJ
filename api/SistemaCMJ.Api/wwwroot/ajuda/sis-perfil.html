Para que serve: dar nome ao perfil e marcar o que os usuários dele podem fazer em cada tela.

Aba Dados

  • Nome (obrigatório, não pode repetir) e Para que serve (aparece na ficha do usuário quando o perfil é escolhido).
  • Ativo: perfil inativo não pode ser dado a ninguém. Só dá para desativar um perfil sem usuários ativos. Perfis de administrador nunca são desativados.

Aba Permissões

  • Cada linha é uma tela, agrupada por módulo; cada coluna é uma ação: Ver (abrir e consultar), Incluir, Alterar, Excluir, Exportar e as ações especiais da tela (baixar, estornar, reabrir mês, desbloquear usuário...).
  • A coluna Tudo marca ou desmarca todas as ações da tela de uma vez.
  • Sem Ver, a tela nem aparece no menu do usuário.
  • A mudança vale para todos os usuários do perfil, menos as exceções individuais de cada um (aba Permissões individuais da ficha do usuário).
  • Só aparecem as telas dos módulos liberados para a empresa. Telas exclusivas do administrador geral (licença, parâmetros) não podem ser dadas a ninguém.
  • As mudanças são gravadas junto com o botão Gravar.

Aba Usuários

  • Quem está neste perfil. Clique para abrir a ficha da pessoa.

Atalhos

  • Ctrl+S grava (com a mesma confirmação do botão); Esc volta para a lista.
