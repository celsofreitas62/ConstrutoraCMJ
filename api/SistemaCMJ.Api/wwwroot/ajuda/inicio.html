Para que serve: ponto de partida do sistema.

Menu

  • Clique no módulo (por exemplo, Cadastros) para ver as telas dele. Use Voltar para subir um nível.
  • Só aparecem os módulos e as telas liberados para o seu usuário.

Em toda tela

  • O botão ? abre a ajuda daquela tela.
  • Quando algo não pode ser feito, abre uma janela explicando; clique em OK para continuar.
  • Para trocar a sua senha, use o link Trocar senha no alto, ao lado do seu nome.
  • Depois de um tempo sem uso, o sistema pede o login de novo.
