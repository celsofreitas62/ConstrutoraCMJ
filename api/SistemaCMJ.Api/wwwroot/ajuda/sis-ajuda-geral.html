Para que serve: reunir num lugar só, dentro do sistema, o que o administrador geral precisa para instalar, manter e diagnosticar o sistema.

Como usar

  • Escolha a página na lista à esquerda, ou escreva no campo Procurar (procura no título e no texto, sem precisar de acento).
  • Ao lado de cada comando há o botão Copiar, para colar no SSMS ou no PowerShell sem erro de digitação.
  • O topo mostra a versão do programa e do banco para a qual a ajuda foi escrita.

Cuidados

  • Só o administrador geral vê esta tela, e cada página aberta fica registrada.
  • A ajuda nunca mostra senhas nem chaves: diz só onde cada coisa está guardada.
