Para que serve: a lista dos tipos que um parceiro pode ter (cliente, fornecedor, funcionário, corretor e os que a empresa criar, como "Prestador de serviço"). Na ficha do parceiro dá para marcar vários tipos.

Como usar

  • + Incluir tipo: acrescenta uma linha em branco. Preencha o código (curto, sem espaços), a descrição e, se quiser, a ordem; depois clique em Gravar na linha.
  • Para mudar um tipo, altere a linha e clique em Gravar nela.
  • Para desativar, desmarque Ativo e grave. O tipo some das fichas novas, mas quem já o tem continua com ele (aparece como "inativo" na ficha).
  • A coluna Parceiros mostra quantos parceiros ativos têm o tipo.
  • Marque Mostrar inativos para ver e reativar tipos desativados.

Cuidados

  • Os tipos do sistema (Cliente, Fornecedor, Funcionário, Corretor) são usados pelas regras do sistema: só a descrição e a ordem mudam.
  • Parceiro sem nenhum tipo marcado fica como "N/A" sozinho; esse tipo não aparece nesta tela.
  • O histórico das alterações fica em Sistema › Auditoria.
  • Só aparecem os botões que o seu usuário pode usar.
