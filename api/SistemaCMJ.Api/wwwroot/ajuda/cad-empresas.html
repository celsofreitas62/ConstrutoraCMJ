Para que serve: as empresas do grupo (a construtora, as SPEs de cada obra, a holding). Todo lançamento, conta bancária e centro de custo pertence a uma empresa.

Como usar

  • Digite parte da razão social, do nome fantasia ou o início do CNPJ; a lista atualiza sozinha.
  • Filtre por Tipo (Construtora, SPE, Holding, Outra) e por Situação.
  • As colunas Contas e Centros mostram quantas contas bancárias e centros de custo ativos a empresa tem.
  • Clique na linha para abrir a ficha. + Incluir abre uma ficha em branco.
  • Exportar Excel baixa a lista que está na tela.

Cuidados

  • Ordem dos cadastros para uma empresa nova: empresa, contas bancárias, conta padrão da empresa, centros de custo.
  • As empresas excluídas ficam na Lixeira até o prazo acabar.
  • Só aparecem os botões que o seu usuário pode usar.
