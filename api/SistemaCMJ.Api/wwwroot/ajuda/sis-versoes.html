Para que serve: ver o que mudou em cada versão do sistema (o que é novo, o que melhorou e o que foi corrigido) e, para o administrador, quando cada atualização foi feita.

Aba Notas

  • Mostra as notas de todas as versões já instaladas, da mais nova para a mais antiga. A versão em uso tem a marca instalada.
  • Cada item tem uma etiqueta: Novo (função nova), Melhoria (algo que já existia ficou melhor) ou Correção (um problema resolvido).
  • Filtros: versão, tipo e busca por parte do texto (ex.: "lixeira"). A lista atualiza sozinha.
  • Exportar Excel baixa as notas que estão na tela.
  • Qualquer usuário pode abrir esta aba: basta clicar no número da versão, no topo de qualquer tela.

Aviso "O que há de novo"

  • Depois de uma atualização, cada pessoa vê uma vez, logo depois de entrar, o resumo das novidades. Entendi fecha o aviso e ele não volta para essa versão; Ver todas as versões abre esta tela.
  • Se a pessoa ficou várias versões sem entrar, o aviso mostra só as mais recentes e diz quantas ficaram de fora (o resto está aqui).
  • Na atualização, as notas também vão por e-mail ao grupo VERSAO_AVISO (ajustável em Sistema › Grupos de e-mail).

Aba Histórico de atualizações

  • Aparece só para quem tem permissão na tela (normalmente o administrador).
  • Mostra cada instalação e atualização: quando, de qual versão para qual, quanto tempo o sistema ficou fora do ar, se deu certo, quem fez e de qual computador.
  • Uma atualização desfeita é aquela em que algo falhou e o sistema voltou sozinho para a versão anterior; nada se perdeu.
