Para que serve: a lista dos bancos usados nas contas bancárias da empresa e nos dados bancários dos parceiros (TED).

Como usar

  • + Incluir banco: acrescenta uma linha em branco. Informe o código de 3 números (ex.: 748 Sicredi, 001 Banco do Brasil), o nome e, se souber, o ISPB (8 números); clique em Gravar na linha.
  • Para mudar um banco, altere a linha e clique em Gravar nela.
  • Para desativar, desmarque Ativo e grave: o banco some das escolhas novas, mas as contas que já o usam continuam.
  • Busque pelo nome ou pelo código; Mostrar inativos mostra os desativados.

Cuidados

  • O código não pode repetir.
  • O histórico das alterações fica em Sistema › Auditoria.
  • Só aparecem os botões que o seu usuário pode usar.
