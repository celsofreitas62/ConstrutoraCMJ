Para que serve: os dados de uma conta bancária, de um caixa ou de uma conta de permuta de uma empresa.

Como usar

  • Empresa: titular da conta. Aberta pela ficha da empresa (botão + Incluir conta), ela já vem escolhida.
  • Descrição: nome curto que aparece nas escolhas (ex.: Sicredi Orion). Não repete na mesma empresa.
  • Tipo: conta corrente, poupança e aplicação pedem banco, agência e conta; Caixa e Permuta não têm banco.
  • Saldo inicial e Data do saldo inicial: o saldo da conta nesse dia, antes de qualquer movimento do sistema. Valores com vírgula nos centavos (ex.: 1.234,56).
  • Concilia pelo extrato (OFX): marque nas contas que serão conferidas com o arquivo de extrato do banco.
  • Mostra o saldo no resumo: desmarque para a conta não aparecer no resumo de saldos da tela inicial.
  • Conta contábil: código da conta no plano do contador, para a exportação contábil.
  • Anexos (ex.: contrato de abertura) e Histórico (quem mudou o quê; dá para voltar como estava).

Cuidados

  • Depois que a conta tem movimento, a empresa, o tipo e o saldo inicial não mudam mais: para acertar o saldo, faça um lançamento de ajuste.
  • O saldo inicial também não muda quando a data cai num mês fechado.
  • Desativar: a conta some das escolhas, mas o movimento continua. Se ela for a conta padrão da empresa ou de um centro de custo, troque a padrão antes.
  • Excluir manda para a lixeira e só vale para conta sem nenhum movimento.
  • Só aparecem os botões que o seu usuário pode usar.
