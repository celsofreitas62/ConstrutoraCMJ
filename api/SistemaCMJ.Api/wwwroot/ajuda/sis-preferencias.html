Para que serve: cada pessoa escolhe como o sistema se comporta para ela, sem mudar nada para os outros. Abre pelo botão ⚙ no alto de qualquer tela.

Como funciona

  • Cada preferência mostra o padrão da empresa. Enquanto você não muda, ela segue esse padrão, e acompanha se os administradores mudarem o padrão em Parâmetros de uso.
  • Quando você muda, aparece a marca Sua escolha. Voltar ao padrão faz a preferência seguir de novo o padrão da empresa.
  • Gravar (ou Ctrl+S) pede confirmação e grava todas as mudanças de uma vez. Voltar (ou Esc) sai sem gravar e avisa se houver alteração.
  • Itens marcados (em breve) ficam prontos numa das próximas versões (calendário da tela inicial e tema claro/escuro).

Tela inicial

  • Abrir a tela inicial em: lista ou calendário (o calendário chega em breve; até lá, abre em lista).
  • Período ao abrir e quantos anos em "Vários anos": como a agenda abre no primeiro acesso do dia. Durante o dia, ela lembra o último período usado neste computador.
  • Mostrar também o que já foi pago ou recebido: sem esta opção, a agenda mostra só o que está em aberto.
  • Mostrar o saldo previsto acumulado: só para quem pode ver os totais.
