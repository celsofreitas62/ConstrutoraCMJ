Para que serve: um cadastro único de clientes, fornecedores, funcionários e corretores. A mesma pessoa pode ter vários papéis (por exemplo, um funcionário que também é fornecedor).

Buscar

  • Digite parte do nome, do nome fantasia, o início do CPF/CNPJ (com ou sem pontos) ou o código da pessoa. A lista atualiza sozinha.
  • Use Papel para ver só clientes, só fornecedores etc.
  • Em Situação, escolha "Inativos" ou "Todos" para achar pessoas desativadas.
  • Pessoas excluídas ficam na lixeira e não aparecem aqui: use o atalho Lixeira de Pessoas no topo (aparece para quem pode ver a Lixeira).
  • A lista mostra no máximo 500 pessoas: se aparecer o aviso, refine a busca.

Botões

  • + Incluir: abre a ficha em branco para cadastrar uma pessoa nova.
  • Exportar Excel: baixa a lista que está na tela num arquivo que o Excel abre (.csv).
  • Clique numa linha para abrir a ficha da pessoa.

Cuidados

  • O CPF aparece mascarado na lista (proteção de dados pessoais). Na ficha ele aparece completo.
  • Só aparecem os botões que o seu usuário pode usar.
