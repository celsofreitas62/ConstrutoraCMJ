Para que serve: um cadastro único de parceiros: clientes, fornecedores, funcionários, corretores e os outros tipos que a empresa criar. O mesmo parceiro pode ter vários tipos (por exemplo, um funcionário que também é fornecedor).

Buscar

  • Digite parte do nome, do nome fantasia, o início do CPF/CNPJ (com ou sem pontos) ou o código do parceiro. A lista atualiza sozinha.
  • Use Tipo de parceiro para ver só clientes, só fornecedores etc.
  • Em Situação, escolha "Inativos" ou "Todos" para achar parceiros desativados.
  • Marque Pendências de cadastro para ver os clientes com parcela a receber em aberto cujo cadastro ainda não serve para emitir boleto. A coluna Cobrança diz o que falta (CPF/CNPJ, endereço completo, e-mail).
  • Parceiros excluídos ficam na lixeira e não aparecem aqui: use o atalho Lixeira no topo (aparece para quem pode ver a Lixeira).
  • A lista mostra no máximo 500 parceiros: se aparecer o aviso, refine a busca.

Botões

  • + Incluir: abre a ficha em branco para cadastrar um parceiro novo.
  • Exportar Excel: baixa a lista que está na tela num arquivo que o Excel abre (.csv), com as colunas Tipos e Cobrança.
  • Clique numa linha para abrir a ficha do parceiro.

Cuidados

  • O CPF aparece mascarado na lista (proteção de dados pessoais). Na ficha ele aparece completo.
  • O nome "Parceiros" pode ser trocado pelo administrador do sistema (parâmetro).
  • Só aparecem os botões que o seu usuário pode usar.
